# 🍽️ ChamFoodie

ChamFoodie is a web-based project designed to make online food ordering easier, faster, and more enjoyable for users in Eldoret, Kenya. The goal of this project is to connect people with local restaurants, cafés, and food joints so they can browse menus, compare options, and order their favorite meals from the comfort of home.

## 🌟 Project Overview

This project was built as a modern food-ordering landing page with a clean and user-friendly interface. It helps users:

- Explore different restaurants and food places
- View restaurant details like cuisine, rating, and location
- Discover top-rated food spots in Eldoret
- Browse popular dishes and local favorites
- Enjoy a smooth and visually appealing browsing experience

## 🧱 How I Built It

This website was created using a simple front-end structure with HTML and CSS to design the layout and styling. I also used a local live preview setup while developing the page, which allowed me to view changes in real time as I built the interface.

This helped me test the appearance, spacing, layout, and overall design before finalizing the project.

## 🍔 Features

- User-friendly food ordering interface
- Restaurant browsing section
- Top-rated restaurant highlights
- Popular food categories and featured dishes
- Local food culture and delivery focus
- Clean, modern, mobile-friendly layout
- Visual appeal with attractive sections and styling

## 🏙️ Featured Food Culture

The project highlights the vibrant food scene in Eldoret by showcasing local restaurants and well-loved dishes such as:

- 🍖 Nyama Choma
- 🍕 Pizza
- 🍔 Burger
- 🍗 Chicken
- 🥛 Mursik

These dishes represent some of the most popular food favorites in the area and add to the city’s rich culinary identity.

## 📍 Project Goal

ChamFoodie aims to provide a smooth and delightful food ordering experience for food lovers in Eldoret. The project focuses on making it easy to discover restaurants, browse menus, and order meals without stress or delay.
